# Prompt ：产品PRD

``` text
现在请你扮演产品经理。

不要考虑实现难度，只考虑用户体验。

目标用户：A股个人投资者。

产品名称：
MrMarket（市场先生）

希望风格像 Notion 一样简洁，像 同花顺 一样专业。

一级菜单：
① 资讯-这里可以看到有价值的财报文章
② 行情-这里可以看到股票的实时行情、K线图、成交量、资金流向等
③ 策略-这里可以创建、修改、删除、启停策略，支持MACD、KDJ、均线、RSI、布林带等自由组合，未来支持Python策略，也可提供AI辅助策略生成或者广场其他用户的策略
④ 回测-这里可以进行历史数据回测，查看策略表现
⑤ 模拟交易-这里可以进行模拟交易，测试策略效果
⑥ 自选股-这里可以添加自己关注的股票，方便查看行情和资讯

简约风格，专业、支持深色模式和响应式布局。

请先输出完整产品PRD，提供一流的产品方案，不要写代码。
```
