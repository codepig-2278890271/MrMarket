# MrMarket（市场先生）

A 股价值投资辅助分析工具 — 本地运行的网站，帮助个人投资者进行多市场行情查看、策略研究和模拟分析。

> 产品命名灵感来自本杰明·格雷厄姆《聪明的投资者》中的「市场先生」寓言。股价短期是投票机，长期是称重机。

## 快速开始

```bash
# 1. 启动全部服务
bash scripts/dev/start.sh

# 2. 浏览器打开
# http://localhost:5173
```

首次运行会自动填充 15 只代表性 A 股的种子数据（含 250 天日 K 线），无需额外配置。

## 投资理念

### 市场先生寓言

本杰明·格雷厄姆在《聪明的投资者》中提出了「市场先生」的著名寓言：

> 假设你持有某家公司的一小部分股份，你有一位合伙人名叫市场先生。他每天都会向你报出一个价格——有时高得离谱，有时低得荒谬——你可以选择以他的价格买入更多，也可以卖出你手中的股份，当然你也可以完全无视他。市场先生并不介意被冷落，他明天还会带着新报价回来。
>
> 关键在于：**市场先生是你的仆人，而非你的向导。** 他的情绪波动是你的机会，而非你的行动指令。

这就是 MrMarket 这个名字的由来。本工具旨在帮助你在市场先生的疯狂报价中，保持理性和纪律。

### 思想渊源

本工具的投资哲学源自格雷厄姆 → 巴菲特 & 芒格 → 段永平这一价值投资脉络：

| 人物 | 核心贡献 |
|------|----------|
| 本杰明·格雷厄姆 | 「市场先生」寓言、安全边际原则 |
| 沃伦·巴菲特 | 能力圈、护城河、以合理价格买伟大公司 |
| 查理·芒格 | 多元思维模型、逆向思考 |
| 段永平 | 「本分」文化、right business / right people / right price |

### 核心原则

**1. 买股票 = 买公司**

股票不是一张价格会波动的纸，而是一家真实公司的部分所有权。买入一只股票前，先问自己：我愿意以当前市值买下这整家公司吗？

**2. 安全边际**

任何估值都存在不确定性。好的投资不是精确计算出公司的内在价值，而是以**显著低于**内在价值的价格买入——这个价差就是你的安全边际。安全边际越大，判断错误时的损失越小。

**3. 市场波动 ≠ 风险**

股价下跌不是风险，永久性资本损失才是。如果你的分析是正确的，市场先生的低价报价恰恰是你加仓的机会。真正的风险来自：看不懂的公司、过高的买入价格、以及被迫在低点卖出的流动性压力。

**4. 能力圈**

只投资你能理解的生意。A 股有 5000+ 上市公司，你不需要看懂每一家。在你的能力圈内做到比市场更懂这几家公司，就足够了。

**5. 长期视角**

> 股市短期是投票机，长期是称重机。—— 本杰明·格雷厄姆

短期价格由情绪和资金驱动，长期价格由企业的真实价值驱动。本工具的设计默认以年为单位思考，而非以天为单位。

**6. 理性对待 A 股**

A 股市场有其特殊性：个人投资者占比高、政策敏感性强、波动率较大。这些特点既是风险，也为有纪律的价值投资者提供了更多的错误定价机会。本工具专注于可量化的数据分析，帮助你在情绪化的市场中保持客观。

### 本工具的定位

MrMarket 不是交易软件，不会替你下单，也不会告诉你「该买什么」。它做的是：

- **呈现数据**：行情、财务指标、历史走势，让你基于事实而非情绪做决策
- **辅助分析**：策略回测、模拟交易，帮你验证想法而非盲从直觉
- **强制纪律**：将你的投资逻辑编码为可回测的规则，用数据检验其有效性

最终，所有买卖决策由你做出。就像巴菲特说的：**「别人贪婪时我恐惧，别人恐惧时我贪婪。」** 本工具帮你在这两种时刻都保持清醒。

## 常用命令

```bash
# 启动
bash scripts/dev/start.sh

# 停止
bash scripts/dev/start.sh stop

# 状态
bash scripts/dev/start.sh status

# 仅启动数据库
docker compose -f docker/docker-compose.yml up -d postgres redis

# 手动启动后端（从 backend/ 目录）
cd backend && python3 -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

# 手动启动前端
cd frontend && npm run dev

# 填充种子数据
python3 scripts/data/seed_data.py

# 同步全量 A 股数据
python3 scripts/data/sync_data.py stocks   # 股票列表
python3 scripts/data/sync_data.py kline    # K 线数据
```

## 设计原则

- **辅助分析，而非替代决策**：不连接券商，不自动下单，只提供数据和分析工具，最终判断由你做出
- **本地优先**：所有数据存储在本地 PostgreSQL，代码完全开源可自由修改，不依赖任何云端服务
- **纪律优先于直觉**：鼓励将投资逻辑编码为可回测、可验证的规则，用历史数据检验想法
- **简单克制**：不堆砌指标，不追求炫酷图表，只呈现对价值判断真正有用的信息
